## 🇬🇧 English

**Code and words, side by side.** I build small Linux tools and write about them, and I also write things that have nothing to do with code.

### 📝 [code-x.md](https://code-x.md) — the blog
Everything I build with code, told honestly: step-by-step tutorials, complete projects, quick snippets, and *the story behind each one*, doubts, mistakes and detours included.
